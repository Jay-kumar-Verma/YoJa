# Machine Learning Workspace for YoJa

This folder contains all the necessary files and scripts for training and validating the machine learning models used in the YoJa project.

## Folder Structure
- **data**: Contains raw and processed data, as well as trained models.
- **notebooks**: Jupyter notebooks for exploratory data analysis and initial model development.
- **scripts**: Python scripts for preprocessing, training, and validation.
